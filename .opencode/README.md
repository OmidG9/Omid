# OpenCode Skills — GHANBARIOMID.IR

Place these folders under:

`.opencode/skills/`

Recommended structure:

```text
.opencode/
└── skills/
    ├── project-audit/
    │   └── SKILL.md
    ├── analytics-engineering/
    │   └── SKILL.md
    ├── security-review/
    │   └── SKILL.md
    └── quality-gate/
        └── SKILL.md
```

These four skills are intentionally project-specific and lightweight. They complement the Master Prompt rather than replacing it.

Recommended workflow:

1. `project-audit` before implementation
2. `analytics-engineering` during analytics/data work
3. `security-review` during security-sensitive work
4. `quality-gate` before declaring the implementation complete
